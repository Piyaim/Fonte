Préversion : nouvelles animations de personnage et nouveau corps dans l'onglet Zones.

- Un personnage articulé remplace le stickman, avec les muscles travaillés qui s'allument pendant l'effort. Choix Homme ou Femme dans le menu ☰.
- Six exercices animés pour l'instant : développé couché, curl haltères, élévations latérales, goblet squat, tirage vertical et pompes. Les autres suivent.
- Le corps de l'onglet Zones est redessiné, de face et de dos.
- Installe cette version par-dessus la précédente : tes données sont conservées.

Les animations ont été construites sans relecture par un coach : en cas de doute sur un mouvement, demande l'avis d'un professionnel.
